# Cinema Ticket Reservation

JavaScript sinema bileti rezervasyon uygulaması.

## Features

- Film seçimi ve seans görüntüleme
- Koltuk rezervasyonu
- Bilet özeti

## Run

Projeyi tarayıcıda aç veya bir local server kullan:

```bash
# VS Code Live Server veya:
npx serve .
```
